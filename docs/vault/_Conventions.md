# Conventions

* Flat folder, notes linked with wikilinks. Tags only for status: `#active`, `#archived`.
* Every code change updates [[Changelog]] and, when behaviour moves, [[App Overview]].
* Move stale notes to an Archive folder instead of deleting them.
* Repo rules in `CLAUDE.md` apply here too: no dashes as connectors in prose.
